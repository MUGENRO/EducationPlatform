# Education Platform

> AI-powered education platform for modern learning, student management, and intelligent educational workflows.

---

## About

**Education Platform** is an AI-native education technology platform developed by **MUGENRO**.

The platform is designed to modernize educational workflows by combining modern web technologies, intelligent automation, student management, learning tools, and AI-powered systems.

The long-term goal is to create an intelligent educational environment where students, educators, and educational organizations can manage learning processes through a single modern platform.

---

## Vision

Education should not be limited to traditional learning management systems.

Education Platform is being developed toward an intelligent environment where software can understand educational processes, automate repetitive tasks, assist students and educators, and continuously improve the learning experience.

**Learn. Automate. Evolve.**

---

## Core Areas

### Student Management

Tools and infrastructure for organizing student information, educational processes, and academic workflows.

### Learning

Modern interfaces and systems designed to support digital learning and educational content.

### Intelligent Automation

Automation of repetitive educational workflows to reduce administrative workload and improve efficiency.

### AI Integration

AI-powered features designed to assist users, analyze educational information, and improve decision-making.

### Educational Analytics

Infrastructure for working with educational data to provide useful insights and support future intelligent features.

## Repository Structure

The repository contains the main application and supporting project infrastructure.

- `app/` — application routes and pages
- `data/` — application and educational data
- `public/` — public static assets
- `.gitignore` — Git configuration
- `AGENTS.md` — AI agent development instructions
- `CLAUDE.md` — AI-assisted development instructions
- `README.md` — project documentation
- `eslint.config.mjs` — ESLint configuration
- `next.config.ts` — Next.js configuration
- `package.json` — project dependencies and scripts
- `package-lock.json` — dependency lock file
- `postcss.config.mjs` — PostCSS configuration
- `tsconfig.json` — TypeScript configuration
